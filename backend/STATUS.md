# Статус серверной части

## Реализовано

API v0.1: пользователи/сессии/CSRF, конфигурации, каталоги, workspace Python и FILE, очередь запусков, worker, журнал этапов, summary, pivot, drill-down, атрибуты/raw, CHECK, HTML и адаптер ИИ.

Настраиваемые массивы/исключения/бакеты; четыре типа изменения; пять выданных checks через индексированный MartAPI. Новая проверка заменяет строки того же CHECK.id в едином отчёте. Raw и код на старте сохраняются как снимки; журнал ведёт к текущему скрипту.

Pivot, фильтры и пагинация списка заявок считаются в SQL. fact_members и покрывающие индексы позволяют искать уникальные заявки без чтения всей витрины. Drilldown token хранит предикаты ячейки, сохраняет контекст конкретного атрибута и принадлежит владельцу запуска. Старые запуски до fact_members нужно пересчитать.
