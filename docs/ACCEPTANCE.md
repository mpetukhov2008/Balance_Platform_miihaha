# Проверка требований жюри

Проверяемая ветка сдачи — `main`. Базовые результаты полного датасета воспроизведены в серверных тестах и Compose CI: **2002 / 502 / 385 / 167**. Числа означают все заявки, заявки с различиями, со сменой решения и со сменой решения при изменении внешних данных. Совпадение с закрытым эталоном организаторов пока не подтверждено: сам эталон команде не предоставлен.

| Критерий | Где показать | Проверка |
|---|---|---|
| Полная обработка и итоговый отчёт | Полный датасет → завершённый прогон → HTML | Compose scenario на 2002 парах |
| Количество различий | Сводка: 502, смена решения: 385 | Эти числа проверяет сквозной тест; сверка с закрытым эталоном остаётся за жюри |
| Четыре типа изменений | CHANGE_TYPE в сводной | SAME, VALUE_CHANGED, ATTRIBUTE_NEW, ATTRIBUTE_LOST; тесты различают null/false/0/отсутствие |
| Процедуры и проверки в конфигурации | FILE/WORKSPACE и параметры | Серверная валидация контрактов и запуск |
| Пять выданных проверок и ссылки | Общая таблица CHECK → заявки | Сквозной сценарий и проверка APP_IDS |
| Изменяемая раскладка | Перенос полей, порядок, фильтры сводной | UI-тесты и настоящий API |
| Журнал этапов | Ход выполнения и журнал | Сохраняемые стадии, сообщения и время |
| Чистая машина | README, Docker Compose | Сборка с нуля в Linux runner, API + PostgreSQL + worker |
| Долгие операции | Очередь, RUNNING, ошибки, готовность результата | Worker и опрос API; ошибочный Python не становится PASS |
| Перезагрузка страницы | Обновить браузер на текущем прогоне | Сессия, конфигурация, очередь и результаты сохранены в SQL |

Дополнительно проверяются личные ZIP-датасеты, их изоляция между аккаунтами, регистрация при разрешённой политике, квоты ИИ, ограничения Docker-runner и восстановление резервной копии в отдельную БД. Внешний платный ИИ не вызывается в CI; ранее полученный реальный ответ YandexGPT подтверждён отдельно и описан в отчёте полного прогона.
