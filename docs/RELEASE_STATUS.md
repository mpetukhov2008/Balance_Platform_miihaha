# Интеграционная версия МИЯУХАХА

Обновлено 07.11.2026. Ветка codex/final-integration включает frontend Claude 67d315d и интеграционные изменения Codex.

Проверено локально на Windows, SQLite, одном worker в trusted-local.

- Production-сборка React/TypeScript проходит. 18 UI-тестов прошли.
- 20 серверных тестов прошли, 2 Docker-теста пропущены.
- Полный прогон 2002 пар занял 81,42 с. Получены 502 заявки с различиями, 385 со сменой решения, 167 со сменой решения при изменении внешних данных. Закрытый эталон жюри недоступен.
- API и собранный frontend работают с одного адреса. В браузере проверены вход и сводка полного отчёта.
- YandexGPT Pro 5.1 успешно обработала искусственную сводку, затем через фоновую задачу API сформировала мнение по агрегатам готового полного отчёта. Получен READY.
- Реальный HTTP-сценарий проверил загрузку HTML с attachment, pivot на 502 изменившиеся заявки, drill-down группы на 167 заявок и получение одного соответствующего атрибута. Итоги сохранены локально в runtime.
- Исправлены SQLite WAL/busy_timeout, повторная запись всей витрины при CHECK, потеря stdout/traceback Python, формат ошибок форм. Pivot-токены публикуются одной транзакцией.
- Реализована повторная генерация ИИ с привязкой к ревизии. Добавлены тесты авторизации Yandex, ограничения входа и безопасных ошибок провайдера.
- Dockerfile собирает frontend отдельным этапом, API обслуживает его вместе с маршрутами приложения.

Локальный Docker daemon недоступен после попытки запуска Docker Desktop. PostgreSQL и контейнерный runner проверяются отдельными CI-задачами текущего коммита. Их результаты необходимо смотреть в GitHub Actions. Полная контейнерная сборка приложения локально не подтверждена.

Для сдачи команде остаются запись и размещение видео до 20 минут, добавление ссылки на него в README и отправка формы организаторов до 8 ноября, 09:30 МСК. Сценарий и сроки находятся в FINAL_DELIVERY_PLAN.md.

Секреты .env, базы runtime и тестовые учётные данные не входят в коммит. В новой установке пользователей создают через backend.manage.
