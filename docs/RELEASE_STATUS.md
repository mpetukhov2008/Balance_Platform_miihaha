Обновлено 07.11.2026 после полной приёмки. Финальная ветка — main; учтены дизайн Claude 789175e, его отчёт 43de021 и интеграционные исправления Codex. Подробный сценарий — SCENARIO_REVIEW.md.

Проверено локально на Windows, SQLite, одном worker в trusted-local.

- Production-сборка React/TypeScript проходит. 18 UI-тестов прошли.
- Объединён новый интерфейс Claude: верхняя навигация, чёрно-оранжевая палитра, логотип, локальный Manrope с кириллицей. Исправлены синхронизация темы редактора, контраст вторичного текста, переполнение карточки заявки и форм на узких экранах, мобильная раскладка сводной.
- На реальном API в браузере проверены конфигурации, запуски, сводка, сводная, переход к 167 заявкам и карточке с выбранным атрибутом, отчёт проверок, мнение ИИ и скачивание HTML. Проверены ширины 319, 390 и 1280 px; ошибок console error/warn на проверенных страницах не обнаружено. Мобильные таблицы прокручиваются внутри своих блоков.
- 21 серверный тест прошёл, 2 локальных Docker-теста пропущены. 18 UI-тестов и сборка прошли после чистого npm ci; npm audit — 0 уязвимостей на дату проверки.
- Полный прогон 2002 пар занял 81,42 с. Получены 502 заявки с различиями, 385 со сменой решения, 167 со сменой решения при изменении внешних данных. Закрытый эталон жюри недоступен.
- API и собранный frontend работают с одного адреса. В браузере проверены вход и сводка полного отчёта.
- YandexGPT Pro 5.1 успешно обработала искусственную сводку, затем через фоновую задачу API сформировала мнение по агрегатам готового полного отчёта. Получен READY.
- Реальный HTTP-сценарий проверил загрузку HTML с attachment, pivot на 502 изменившиеся заявки, drill-down группы на 167 заявок и получение одного соответствующего атрибута. Итоги сохранены локально в runtime.
- Исправлены SQLite WAL/busy_timeout, повторная запись всей витрины при CHECK, потеря stdout/traceback Python, формат ошибок форм. Pivot-токены публикуются одной транзакцией.
- Реализована повторная генерация ИИ с привязкой к ревизии. Добавлены тесты авторизации Yandex, ограничения входа и безопасных ошибок провайдера.
- Dockerfile собирает frontend отдельным этапом, API обслуживает его вместе с маршрутами приложения.

Полное развёртывание Compose на Linux подтверждено GitHub Actions для версии 27a17f0 (run 42407693143): сборка с нуля, PostgreSQL, API, worker, runner и полный HTTP-сценарий на 2002 парах. Все утверждаемые числа и переходы совпали; вывод CHECK, замена проверки, ошибка Python, HTML и разделение аккаунтов проверены. Локальный Docker Engine Windows по-прежнему возвращает HTTP 500, поэтому для этой машины подтверждён trusted-local. Нативный macOS-запуск отдельно не проверялся.
