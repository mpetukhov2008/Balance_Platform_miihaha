# Проверка полного датасета

Актуализировано 07.11.2026. В репозитории опубликован полный набор организаторов с разрешения владельца: `Исходники/data/RUN-20260827-0001`. Он содержит 2 002 заявки, 4 004 JSON-ответа и manifest.json (4 005 файлов, 21 044 567 байт). Каталог `RESULTS` содержит `BEFORE_MASTER` и `AFTER_BETA` и распознаётся как datasetId `full`.

## Подтверждённый результат

Первый успешный измеренный прогон Windows/SQLite/trusted-local занял 81,42 с:

| Показатель | Значение |
|---|---:|
| Всего заявок | 2 002 |
| Заявки с различиями | 502 |
| Заявки со сменой решения | 385 |
| Смена решения при изменении внешних данных | 167 |

Повторный прогон из чистой копии по README, с новой БД, конфигурацией через UI и процедурой из рабочей области, дал те же числа. Он включал пять проверок и реальную YandexGPT и занял около 85 с на этой машине. После завершения в браузере проверены сводная, перестановка полей, фильтры, переход к 167 заявкам и атрибуту 760 → 620, добавление своей проверки и HTML. Подробности и ограничения — [отчёт приёмки](SCENARIO_REVIEW.md).

В ранней версии полный набор превышал лимит вывода процедуры 100 МБ. Сейчас конечный лимит — 512 МиБ, память runner — 2 ГБ, время процедуры — 180 с с настройкой `SCRIPT_TIMEOUT`. JSON-вывод буферизуется для контейнерного транспорта. Эти лимиты не означают подтверждение масштаба 20 000 заявок.

## Воспроизведение

Из корня установленного проекта:

```powershell
.\.venv\Scripts\python.exe -m backend.validate_dataset --dataset full --trusted-local
```

В Linux/macOS используйте `.venv/bin/python`. Команда создаёт отдельную БД и JSON с агрегатами в `runtime/validation-*`, не добавляет прогон в браузерный аккаунт и не включает ИИ. `trusted-local` используется только для проверенного кода. Для обычного пользовательского сценария запускайте через интерфейс по README. Docker-приёмка воспроизводится отдельным workflow `Compose scenario`.

Закрытый эталон жюри не предоставлен: совпадение 502/385 с ним не заявляется. Локальные БД и отчёты в Git не входят; исходный датасет уже находится в `main`, хотя `.gitignore` предотвращает случайное добавление новых локальных файлов data.
