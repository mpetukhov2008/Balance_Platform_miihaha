# Подключение полного набора

Обнаружен Исходники/data/RUN-20260827-0001: 2002 заявки, 4004 JSON-ответа и manifest.json. Всего 4005 файлов, 21044567 байт. Структура распознана каталогом; datasetId=full доступен локально.

Первый прогон через worker/trusted-local остановлен на NORMALIZE через 5.01 с: результат процедуры превысил прежний лимит вывода 100000000 байт. Это техническая ошибка исполнения, не результат проверки данных.

Исправление: стандартный лимит SCRIPT_OUTPUT_LIMIT увеличен до 536870912 байт (512 МиБ), Docker RUNNER_MEMORY — до 2g, оба настраиваются окружением. Лимиты остаются конечными; автоматического отключения ограничений нет. Их достаточность для полного набора ещё не подтверждена.

Повторная обработка заблокирована автоматической проверкой среды, сославшейся на возможную телеметрию Visual Studio. Сохранённого успешного результата нет. Число различий, итоги пяти проверок и скорости полного набора пока неизвестны.

Воспроизводимая команда для подтверждённой среды: python -m backend.validate_dataset --dataset full. По умолчанию используется Docker-исполнитель. Параметр --trusted-local допустим только для проверенного кода: он не создаёт песочницу. Скрипт сохраняет статус и агрегаты в игнорируемый runtime/, не отправляет результаты в GitHub и не включает ИИ-мнение.

Публикация data в публичный репозиторий остановлена автоматической проверкой: требуется конкретное согласие на раскрытие идентификаторов, скоринговых баллов и решений в mpetukhov2008/Balance_Platform_miihaha. Ветка с данными не обновлялась. Датасет остаётся исключённым из обычного git add через .gitignore.
