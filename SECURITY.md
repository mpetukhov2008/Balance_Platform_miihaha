# Безопасность проекта

Поддерживается текущая версия ветки `main`. Обнаруженную уязвимость сообщайте команде приватно через контакт поддержки в приложении или личное обращение владельцу репозитория. Не публикуйте ключи, пароли, дампы, исходные заявки и готовые эксплойты с персональными данными в открытом issue.

В сообщении укажите затронутый commit, режим запуска, необходимые права, минимальные действия воспроизведения и фактический результат. Используйте искусственные данные и свой тестовый аккаунт. Не выполняйте нагрузочные атаки на внешний сервер без отдельного согласования.

Границы защиты и проверенные исправления: [SECURITY_REVIEW.md](docs/SECURITY_REVIEW.md). Эксплуатация и резервное копирование: [PUBLIC_ACCESS.md](docs/PUBLIC_ACCESS.md). Публичный доступ с пользовательским Python допустим только с изолированным контейнерным исполнением. trusted-local не является песочницей.
